## Decisions made today

1. **Primary uncertainty model is now CV** (Alex: "use the CV model").
   - Formula: c = c₀ + c_cv·CV, with σ = c|Q′| ⊕ σ₀, inside the existing quasi-likelihood.
   - CV is the residual temporal SD / |mean| of each recording's own Q(t), after removing three cardiac harmonics.
   - Fitted on 4,562 same-tile junctions: **c₀ 0.29, c_cv 0.154**.
   - Code: `reconcile/reliability.py`, with `PROFILE_TERM = "cv"` and `temporal_cv(m)`. `c_a` is kept as 0.0 so old consumers don't break.
   - Inflow is **6.49 nL/s (L 2.67 / R 3.83, 41 % left)**.
   - Held-out error vs alignment:

     | test | CV | alignment |
     |---|---|---|
     | leave-one-recording-out, all recordings | ×1.779 | ×1.792 |
     | leave-one-recording-out, trusted | ×1.455 | ×1.442 |
     | 25 % withheld | ×1.488 | ×1.487 |

   - Alignment calibrates better at junctions (held-out NLL −13224 vs −12926), so error bars on the noisiest recordings are about 1.3× tight. Alignment moves to the SI.
2. **Heart-rate gain normalisation is SI only** (`reconcile/gain.py` DEFAULT = None).
   - Tiles 20 and 28 differ by 5.5 % in heart rate but 29 % in gain.
   - Gains swing 0.5–2.4 while heart rate is flat (tiles 21–53).
   - No heart-rate law is defensible.
3. **Rejected uncertainty models.** The common failure: weights fixed from the measured value give low readings ∝ 1/Q̄² weight, so total inflow collapses.

   | model | outcome |
   |---|---|
   | fixed-variance projection, σ = c\|Q̄\| | inflow halves, ×1.6–1.9 |
   | repeat-recording SD, fixed weights | inflow 2.8–3.3, ×1.9–2.0 |
   | reviewer's σ² = α²Q′² + β²s² (α 0.34, β 0.22) | fixes the corridor (symmetry costs +115), but ×1.52–1.60 and inflow 4.9 |

4. **Fig 7 change:** arterial cuts with net inflow < 0.02 nL/s are closed (11 of 33: 6 tiny withdrawals plus 5 near-zero inflows). Agreement is unchanged (r_log 0.670), and closed cuts aren't drawn. Unmeasured vessels in the Q′ map are now coloured by Q′ (conservation-set). A `FIG7_SYM=1` mode writes `figures/fig7_sym/` with the reconciliation forced to 50 % left: r_log is the same 0.670.
