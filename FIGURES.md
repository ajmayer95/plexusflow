# Paper figures — scripts and inputs

Every main-text and SI figure is generated by a script in `scripts/`. All scripts share `scripts/plos_style.py`
(PLOS Comp Biol style: Arial, ≤ 7.5 in wide, text ≥ 8 pt, 12 pt panel letters; writes `.png`, `.pdf` and an LZW `.tif`).

Data are **not** in this repository. Scripts read a stage folder (default: Somites21, `PlexusFlow21S/`) located via
`PLEXUSFLOW_STAGE`; figures are written to `$PLEXUSFLOW_STAGE/figures/figN/`. Raw tile movies are found through the
stage config (`raw_video_dir`). To run: `PLEXUSFLOW_STAGE=/path/to/PlexusFlow21S python3 scripts/make_figureN.py`.

| Fig | Content | Script | Main inputs (in the stage folder) |
|---|---|---|---|
| 1 | Acquisition: imaging setup, per-tile 250 fps movies → projection, registration of one tile (best rigid vs manual affine), stitched mosaic + acquisition order | `make_figure1.py` | `figures/fig1/setup.png` (drawing), `videos_realtime/`, `tiles/maxmed/`, `stitch/positions.json`, `fuse/organ_fusion.tif` |
| 2 | Mosaic → vessel graph: whole-organ mosaic / probability / mask / graph; mapping into one tile's frame (A⁻¹) | `make_figure2.py` | `fuse/maxmed.tif`, `fuse/probs_logit.tif`, `mask/mask.tif`, canonical graph |
| 3 | Flow in one vessel: optical flow, parabolic profile fits, per-section mean flux, Q(t) + harmonic model | `make_figure3.py` | `batch_kl_inputs/tile_36.pkl.gz`, raw tile movie, canonical graph |
| 4 | Simultaneously recorded vessel pairs: relative first-harmonic amplitude increases / decreases along a path | `make_figure4.py` | canonical graph (`measurements_piv`), `videos_realtime/` |
| 5 | Effective vascular domain: anatomy cartoon, true boundaries (V₁, V₂, dorsal aorta), effective arterial cuts | `make_figure5.py` | `figures/fig5/anatomy.png` (drawing), canonical graph, `fuse/organ_fusion.tif` |
| 6 | DC measurement reliability, held-out calibration, conservation-consistent reconciliation | `make_figure6.py` | `results/reliability_model_v1.json`, `results/dc_reconciled_v2.pkl`, `batch_kl_inputs/` |
| 7 | Whole-organ DC: reference field Q′ vs passive Poiseuille prediction (soft equal-venous-pressure penalty), local agreement, radius controls | `make_figure7dc.py` | `results/dc_reconciled_v2.pkl`, canonical graph |
| 8, 9 | Pulsatile regime (transient vs retained recordings, repeat-vessel waveform reproducibility); tile-clock synchronisation and organ phase map (one script, two figures + SI; writes `figures/fig8/`, `figures/fig9/`) | `make_figure7.py` | `results/ac_field_v7.pkl`, canonical graph |
| 10 | Pulsatile flow: measured vs distributed RC network (maps on the Fig 9 phase reference, PI residual, RMS scatter), profiled distensibility fit, Q/Q̄ waveforms; SI stiff / fitted / compliant | `make_figure10.py --bc-json $PLEXUSFLOW_STAGE/results/ac_estimate_v8.json` | `results/ac_field_v7.pkl`, `results/ac_estimate_v8.json` |

After re-rendering, `python3 scripts/collect_figures.py` copies Figs 1–10 to `$PLEXUSFLOW_STAGE/figures/latest/` (Fig1–Fig10 .tif/.pdf/.png + README with render dates).

Supplementary figures are written by the same scripts (`*_S_*` / `*_supp_*` files in the same output folder).

Superseded versions kept for reference: `make_figure2_registration_old.py`, `make_figure3_meanflow_old.py`,
`make_figure4_pulsatile_old.py`, `make_figure6v3.py`. The script for Figs 8–9 (`make_figure7.py`) still carries older numbering; it writes `figures/fig8/` and `figures/fig9/`.
